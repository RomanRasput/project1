# Тест на скорость печати
---
## Цель
---
Создать продукт, позволяющий пользователю узнать свою скорость печати.
## Что было использовано:
---
- PyQt6
- pymorphy3
- как скачать:
```
    python -m venv venv
    venv/Scripts/activate
    pip install PyQt6
    pip install pymorphy3
    pip install -U pymorphy3-dicts-ru
```
## Возможности
---
- __Проверка скорости печати:__
тест для проверки.
- __Генерация строк__
генерация индивидуальных строк каждый тест
- __Сохранение результатов__
результат каждого теста может быть сохранён и просмотрен
